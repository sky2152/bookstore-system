🎨 UML图使用说明

🌐 在线渲染PlantUML ✏️ Draw.io画图工具

📖 方法一：使用PlantUML在线渲染（推荐！）

1 打开 PlantUML在线网站
2 打开任意一个 .puml 文件，复制全部内容
3 粘贴到PlantUML网站的输入框中
4 点击页面下方的 PNG 或 SVG 按钮导出图片
5 保存图片到电脑

📖 方法二：使用Draw.io手动绘制

1 打开 Draw.io
2 选择保存位置（推荐保存到设备）
3 左侧菜单选择 UML → 对应图类型
4 按照示例图的样子绘制
5 File → Export as → PNG 导出
